## 📖 About

Voltera is an AI-powered electronics learning platform designed to help students, hobbyists, and engineers understand electronic components, embedded systems, and circuit concepts through an intuitive and modern interface.

The platform offers a searchable electronics component library, detailed specifications, pin configurations, applications, and an AI Tutor (local version powered by Ollama) to make learning interactive and practical.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/sanjibani-129/Voltera-Studio.git
```

Move into the project

```bash
cd Voltera-Studio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

# 🤖 AI Tutor

The AI Tutor is powered locally using **Ollama**.

Install Ollama

```
https://ollama.com
```

Download the model

```bash
ollama pull qwen2.5:3b
```

Run

```bash
ollama serve
```

The tutor will then be available in the local development environment.
